# Material Color Utilities

This project brings Johann Dirry's Material Design 3 color engine into the Neumorphism solution. The library includes the source needed to generate tonal palettes and dynamic roles. See the [original project in MaterialDesignInXamlToolkit](https://github.com/MovGP0/MaterialDesignInXamlToolkit/tree/98edec3a0b96ef272c587b14bcd67ef5f928a7ed/src/MaterialDesign3.MaterialColorUtilities) and its [license](LICENSE).
